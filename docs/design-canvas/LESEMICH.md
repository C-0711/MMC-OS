# GitChain — Design-Canvas, alle Arbeitsdateien
Stand: 30.08.2026 · erzeugt in der Cowork-Design-Sitzung

## Sofort anschauen
`gitchain-einfache-oberflaeche.html` im Browser öffnen — das ist das komplette Canvas
(9 Seiten, 44 Artboards) mit Editor, auch offline. Online-Fassung: als Artefakt auf claude.ai
(gleiche Datei, dort mit Speichern/Export).

## Die Seiten
1. Ist-Stand — die einfache Oberfläche, wie sie auf Branch claude/git-ansicht-eckdaten steht (blaues Glas)
2. Navigation — drei verworfene Richtungen (Fall × Ansicht)
3. macOS — Seitenleisten-Fassung (verworfen zugunsten der OS-Sprache)
4. Teams ablösen — CTAX als ein Fall statt sechs Kanäle
5. Ohne Ordner — Inhalt statt Verzeichnis (Buderus, echte Zahlen)
6. iOS — Telefon-Fassung im blauen Glas (Stimmungs-Archiv)
7. OS-Sprache — DIE VERBINDLICHE FASSUNG: 7 Reihen, kompletter Lebenszyklus
   (Heute, Beweise, Fall, Übernahme/Übergang/Vereinbarung, Anruf/Text,
   Freunde/Gruppe, Leseplatz/Tisch, Einladen, Suche, Rückruf)
8. Onboarding — Null-Fragen-Weg (gültig) + verworfener Frage-Weg
9. Bausteine — das Übergabe-Blatt mit allen Maßen und Hex-Werten

## Dateien
- *.dc.html — je ein Artboard (Os* = OS-Sprache, Ob* = Onboarding, Ios*/Mac*/Nav* = Archiv)
- canvas.json — Layout, Seiten, Notizen
- os-tokens.css — die Design-Tokens für den Code
- _os.part / _mac.part / _ios.part / _head.part — geteilte Stilblöcke der Artboards

## Ändern
Artboard-Datei editieren, dann neu zusammensetzen (Claude-Design-Skill, seed-canvas) —
oder direkt im veröffentlichten Artefakt klicken und speichern.
