Die Leiste des Containers
Sie wohnt am Wurf-Platz des Stroms — dieselben Sinnbilder wie überall im OS, aber alles wirkt IN diesem Fall: jeder Griff wird ein Commit auf diesen Container. Links die fünf, die etwas hineinbringen; rechts die sechs, die mit dem Vorhandenen arbeiten.
HineinlegenDatei, Foto, Mail, API-Stand — wird Eingang im Strom
Fragender Assistent antwortet im Strom — mit [n], für alle
Anrufenmit Fall-Kontext — Mitschrift wird Strom-Objekt
MeetVideo mit geteiltem Leseplatz — Aufzeichnung ✓
Studioder Funke: Präsentation, Podcast, Karten — mit Zitat
LesenLeseplatz & Tisch — das Original, das Rechteck
Suchennur in diesem Fall — µs, lokal
Berichtsignierte Fassung — das amtliche Stück
Teileneinladen — „Sehen darf" steht immer dabei
Zeitjeder Stand des Stroms bleibt ansehbar
MitnehmenPhone-Klon, Bundle, PDF/A + container.json
NEU IM SINNBILD-VERTRAG: der funke (studio) — vier spitzen, haarlinie, keine füllung. alle übrigen sinnbilder unverändert aus dem OS-blatt.
REGELN: die leiste ist fall-gebunden — jeder griff committet auf DIESEN container · zustände wie überall (punkt olivgold/rosé, nie zahlen) · wegwerfen wohnt nicht in der leiste, sondern hinter „zeit" — ein ende ist kein alltagsgriff
